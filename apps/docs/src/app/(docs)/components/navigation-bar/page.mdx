## Basic

A navigation bar switches between 3–5 top-level destinations on compact windows. This is the
expressive 64dp short bar; the active pill expands from the center when a destination is
selected. Mark the current destination with `active` — it also announces as `aria-current="page"`,
so items work as links via `render` without extra wiring.

<NavigationBarBasic />

## Horizontal items

On medium windows (like a phone in landscape), switch items to `iconPosition="start"` so icon and
label share one pill, and group them with `arrangement="centered"` — the bar insets the group per
MD3's item-count table (3 items span 60% of the bar, up to 6 spanning 90%).

## With badges

```tsx
import { Badge } from "@brijbyte/md3-react/badge";
```

```css

```

Pass `badge` to anchor a Badge to the icon's top-right corner. Badges are visual only — put the
count in the item's `aria-label` when it's meaningful.
